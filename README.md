
# Information Retrieval Course

The present repository contains a project conducted for the Information Retrieval course of University of Ioannina, in which my team and I created a song-related search engine.



## 📌 Main Goals

-  Design a song-related search engine, with the help of the Lucene library, which specializes in information retrieval
-  Allow the user to ask questions regarding the search for any characteristic of a song (such as the artist, title, album, release date and lyrics)
-  Give the user the ability to sort the result based on a specific characteristic
  
## 🧑‍💻 Technologies

- **Lucene** library is used for the information retrieval
- **Java Swing** is used for the GUI

## 📊 Datasets

All information about the songs were obtained from Kaggle (https://www.kaggle.com/datasets/deepshah16/song-lyrics-dataset).
## 💻 How to run
- Import project on Eclipse
- Add all the libraries from the *jars* folder to the project's build path
- Execute the *Indexer.java* class in order to create the index
- Execute the *WindowSearchEngine.java* class in order to start the search engine
